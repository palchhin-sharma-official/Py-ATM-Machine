# PyATM Machine

A simple, console-based ATM Machine simulator developed using Python.

This project demonstrates core Python programming concepts through a practical banking simulation. Users can create a PIN, access the ATM menu, check their balance, deposit money, and withdraw money.

## Features

- Configurable 4-digit PIN
- PIN verification
- Check account balance
- Deposit money
- Withdraw money
- Maximum withdrawal limit of ₹20,000 per transaction
- Insufficient balance validation
- Invalid input handling
- Menu-driven interface

## Technologies Used

- Python
- Python built-in modules and functions

## Installation

1. Clone this repository:

git clone YOUR_REPOSITORY_URL

2. Open the project folder:

cd PyATM-Machine

3. Run the application:

python main.py

## How It Works

1. Start the application.
2. Create a 4-digit PIN.
3. Enter your PIN to access the ATM.
4. Select an operation from the menu.
5. Perform deposits, withdrawals, or balance checks.
6. Select Exit to close the application.

## Learning Objectives

This project demonstrates:

- Python functions
- Conditional statements
- While loops
- User input handling
- Exception handling
- Modules and imports
- Return statements
- Basic project organization

## Limitations

This is a learning project and does not connect to a real banking system. Account information is stored temporarily and resets when the program restarts.
